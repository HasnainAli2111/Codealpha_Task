
# CodeAlpha Task 1: URL Shortener

## Project Overview
This project is a simple URL Shortener developed using Python, Flask, and SQLite. It converts long URLs into short links that can be used to access the original URLs.

## Technologies Used
- Python
- Flask
- SQLite
- HTML and CSS

## Features
- Enter a long URL.
- Generate a short URL.
- Redirect users to the original URL.
- Store URL records in an SQLite database.

## How to Run
1. Install Python.
2. Install Flask using `pip install flask`.
3. Run the application using `python app.py`.
4. Open `http://127.0.0.1:5000` in your browser.
